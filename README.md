# University Faculty Information Tracker

An offline CLI directory and search engine for VIT-AP University faculty records. The project pairs a Python web synchronizer that harvests live institutional directory data with a zero-dependency C query engine for fast local lookups, analytics, audit logging, and binary backup management.

## Project Architecture

- **`tracker.c`**: The core C search and analytics engine. Dynamically loads the flat-file database into heap memory and provides an interactive terminal interface for multi-token name searches, school filtering (`SCOPE`, `SENSE`, `SAS`, `SMEC`, `VSB`, `VSL`, `VISH`, `SBST`), cabin/location lookups, departmental distribution metrics, and binary archive export/restore (`tracker_backup.bin`).
- **`faculty_database.txt`**: Pipe-delimited flat-file database (`Name|Designation|Cabin|School|Email`) consumed by the C engine at startup.
- **`sync_faculty.py`**: Automated Python crawler that resolves dynamic Next.js data chunks from `https://vitap.ac.in/faculty`, sanitizes profile metadata, and generates `faculty_database.txt`.
- **`tracker_audit.log`**: Append-only audit log generated by the C application recording query timestamps, search types, query strings, and match counts.

## Compilation and Execution

### Optional: Synchronize the Faculty Database

To fetch the latest faculty directory data before running the tracker:

```bash
python sync_faculty.py
```

### Windows (MinGW / GCC)

```powershell
gcc tracker.c -o tracker.exe
.\tracker.exe
```

### Linux and macOS (GCC)

```bash
gcc tracker.c -o tracker
./tracker
```
